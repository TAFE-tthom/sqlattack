## Capitalisation

You have been tasked with outputting the list of names but with capitalisation. You will need to use a mix of functions to achieve this.

Consider the following functions:

* `SUBSTRING`
* `LOWER`
* `UPPER`
* `CONCAT`


Hints:

* Consider how you can use `SUBSTRING` to retrieve a portion of string.
* `LOWER` function will transform all the characters to lower case.
* `UPPER` function will transform all the characters to upper case.
* You can call a function as an argument for another function.
  Example: `CONCAT(UPPER(username), '@', UPPER(domain))`

* You only need to use `SELECT`.

Do note, you can take the value that would be returned by the function as an argument for another - This bit of information is crucial to solve this problem.

Make sure you only output changed `first_name` and `last_name`.
