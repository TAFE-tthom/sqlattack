
## Age Validation

As part of running an platform for selling tickets to concerts, a common requirement is to ensure that purchases are only conducted by users who have been validated for being over 18.

You have been tasked with constructing the following table.


* `users`
  * `user_id`, `INTEGER`, the id is also a primary key for this table.
  * `username`, `VARCHAR(200)`, stores the username up to 200 characters long.
  * `email`, `VARCHAR(200)`, stores the user's email address
  * `age_checked`, `BOOLEAN`, if the user is 18 years old or over, then the user has been listed as someone who can purchase tickets.


---

* Use a `CHECK` constraint as part of defining the table that will need to use the `age_checked` column.
